# Live Go
## ライブの準備・費用管理アプリケーション
[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-5ymytvlf)

### 1.概要（Overview）
Live Go は、音楽ライブやフェスに特化した「持ち物チェックリスト」と「費用管理」機能を備えたWebアプリケーションです。ライブ初心者の不安を解消し、ライブに伴う準備のハードルを下げることを目的として開発しました。

## 開発の背景と目的
全国各地の音楽ライブへ遠征する中で、チケット代だけでなく、夜行バスや新幹線、飛行機などの交通費、宿泊費、そしてグッズ代など、全体の予算管理が煩雑になるという課題を感じていました。
情報科学を学ぶ中で得たプログラミングの知識を活かし、エンターテインメントの裏側を支えるシステムや、ファンがより純粋にライブを楽しめるようなツールを作りたいという思いから、このLive Goを開発しました。

## 主な機能
- **イベントごとの予算管理:** チケット代、交通費、宿泊費、グッズ代などを項目別に記録・計算。
- **遠征計画の最適化:** 複雑になりがちな遠征費用の全体像を可視化。
- **直感的なUI:** ユーザーがストレスなく入力・確認できるクリーンなデザイン。

## 開発環境
- **言語:** TypeScript
- **フレームワーク/ビルドツール:** Vite
- **スタイリング:** Tailwind CSS
- **パッケージ管理:** npm

## 設定
```bash
1.リボジトリをクローンする
git clone [https://github.com/uw-Hiro/Live_Go.git](https://github.com/uw-Hiro/Live_Go.git)

2.プロジェクトのディレクトリに移動します。
cd Live_Go

3.必要なパッケージをインストールします。
npm install

4.開発用サーバーを立ち上げます。
npm run dev

5.ブラウザで http://localhost:5173（またはターミナルに表示されたURL）にアクセスすると、アプリが表示されます。
