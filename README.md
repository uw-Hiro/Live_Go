# Live Go
## ライブの準備・費用管理アプリケーション
[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-5ymytvlf)

## 1.概要（Overview）
Live Go は、音楽ライブやフェスに特化した「持ち物チェックリスト」と「費用管理」機能を備えたWebアプリケーションです。<br>
ライブ初心者の不安を解消し、ライブに伴う準備のハードルを下げることを目的として開発しました。

## 2.制作背景・目的 (Why I built this)
全国各地の音楽ライブへの遠征を頻繁に行う中で、友人から「準備や出費に関する管理が大変で不安がある」という相談を受けたことが開発のきっかけです。  

遠征時には以下のような課題が発生しがちです：
- **多岐にわたる支出**: チケット代、交通費、宿泊費、グッズ購入費など、費用が分散し全体の把握が困難。
- **持ち物管理の複雑さ**: 会場や天候に応じた準備が必要で、忘れ物のリスクが高い

これらの「不安」を解消し、ライブ前のワクワク感を最大限に高められるようなサポートツールを提供したいと考え、本サービスを構築しました。

## 4.主な機能
- **日程別持ち物チェックリスト**  
ライブの日程やイベント特性に合わせたカスタムチェックリストを作成・管理。  
- **費用の自動計算・可視化**  
複雑になりがちな遠征費用の全体像を可視化。

## 5.開発で工夫した点・苦労した点 (Challenges & Solutions)
- **直感的な UI/UX デザイン**  
ライブ初心者やスマートフォンからの屋外利用を想定し、極力シンプルで迷わない画面構成を設計しました。<br>
視認性と操作性を優先し、ストレスのない利用体験を追求しています。
- **効率的な課題解決プロセス**  
開発中の実装課題や構造設計に行き詰まった際は、生成AIツールを活用。<br>
課題を論理的に分解・整理することで、迅速かつ確実な解決策を導き出しました。

## 6.今後の展望 (Future Features)
プロダクトのさらなる品質向上および運用プロセスの効率化を目指し、以下のアップデートを予定しています。  
- **バックエンドの刷新**: Ruby on Railsへのフレームワーク移行
- **開発環境の最適化**: Docker を用いたコンテナ化による環境依存の排除
- **本番環境の構築**: AWSへのデプロイと一般公開

## 7.ローカル環境での起動方法 (Getting Started)
以下の手順で、お手元のPC（ローカル環境）でアプリを起動できます。  

```bash
1.リボジトリをクローンする
git clone [https://github.com/uw-Hiro/Live_Go.git](https://github.com/uw-Hiro/Live_Go.git)

2.プロジェクトのディレクトリに移動します。
cd Live_Go

3.必要なパッケージをインストールします。
npm install

4.開発用サーバーを立ち上げます。
npm run dev
```

### 1.ブラウザで http://localhost:5173（またはターミナルに表示されたURL）にアクセスすると、アプリが表示されます。
