# Live Go
## ライブの準備・費用管理アプリケーション
[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-5ymytvlf)

## 1.概要（Overview）
Live Go は、音楽ライブやフェスに特化した「持ち物チェックリスト」と「費用管理」機能を備えたWebアプリケーションです。<br>
ライブ初心者の不安を解消し、ライブに伴う準備のハードルを下げることを目的として開発しました。

## 2.制作背景・目的 (Why I built this)
全国各地の音楽ライブへの遠征を頻繁に行う中で、友人から「準備や出費に関する管理が大変で不安がある」という<br>
相談を受けたことが開発のきっかけです。  

遠征時には以下のような課題が発生しがちです：
- **多岐にわたる支出**: チケット代、交通費、宿泊費、グッズ購入費など、費用が分散し全体の把握が困難。
- **持ち物管理の複雑さ**: 会場や天候に応じた準備が必要で、忘れ物のリスクが高い

これらの「不安」を解消し、ライブ前のワクワク感を最大限に高められるようなサポートツールを提供したいと考え、<br>
本サービスを構築しました。

## 3.使用技術 (Tech Stack)
| カテゴリ | 技術スタック |
| --- | --- |
| フロントエンド | HTML, CSS, JavaScript |
| バックエンド | PHP, TypeScript |

## 4.主な機能
- **日程別持ち物チェックリスト**  
ライブの日程やイベント特性に合わせたカスタムチェックリストを作成・管理。  
- **費用の自動計算・可視化**  
複雑になりがちな遠征費用の全体像を可視化。

## 開発環境
- **言語:** TypeScript
- **フレームワーク/ビルドツール:** Vite
- **スタイリング:** Tailwind CSS
- **パッケージ管理:** npm

## 設定
```bash
1.リボジトリをクローンする
git clone [https://github.com/uw-Hiro/Live_Go.git](https://github.com/uw-Hiro/Live_Go.git)

2.プロジェクトのディレクトリに移動します。
cd Live_Go

3.必要なパッケージをインストールします。
npm install

4.開発用サーバーを立ち上げます。
npm run dev

5.ブラウザで http://localhost:5173（またはターミナルに表示されたURL）にアクセスすると、アプリが表示されます。
