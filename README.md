# Live Go — ライブプランナー

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-5ymytvlf)

「Live Go — ライブプランナー」は、音楽ライブやイベント遠征に特化した予算・スケジュール管理アプリケーションです。

## 開発の背景と目的
全国各地の音楽ライブへ遠征する中で、チケット代だけでなく、夜行バスや新幹線、飛行機などの交通費、宿泊費、そしてグッズ代など、全体の予算管理が煩雑になるという課題を感じていました。

情報科学を学ぶ中で得たプログラミングの知識を活かし、エンターテインメントの裏側を支えるシステムや、ファンがより純粋にライブを楽しめるようなツールを作りたいという思いから、この「Live Go」を開発しました。ITの力で、遠征の計画から実行までのストレスを減らすことを目指しています。

## 主な機能
- **イベントごとの予算管理:** チケット代、交通費、宿泊費、グッズ代などを項目別に記録・計算。
- **遠征計画の最適化:** 複雑になりがちな遠征費用の全体像を可視化。
- **モダンで直感的なUI:** ユーザーがストレスなく入力・確認できるクリーンなデザイン。

## 技術スタック
- **言語:** TypeScript
- **フレームワーク/ビルドツール:** Vite
- **スタイリング:** Tailwind CSS
- **パッケージ管理:** npm
